# GPTLock 商店文案（简体中文）

## 名称

GPTLock

## 短描述

锁定 ChatGPT 网页聊天的模型与推理偏好，并通过请求与响应证据提示异常切换。

## 完整描述

GPTLock 是面向 ChatGPT 官方网页聊天的第三方浏览器扩展，用于保存并应用你选择的模型与推理偏好，并在相关聊天请求上提供请求锁定和响应证据确认。

当你经常使用固定模型或推理强度时，GPTLock 可以减少重复设置，并在页面选择、实际请求状态或响应证据出现不一致时给出清晰提示，帮助你判断当前偏好是否真正应用。

主要功能：

- 保存并应用常用模型与推理强度偏好；
- 在 `chatgpt.com` 的相关聊天请求上执行请求锁定；
- 显示本地核心、请求锁定器、页面选择和响应证据状态；
- 提供自动验证流程，用固定测试消息收集必要的验证证据；
- 支持 Windows / Linux，并面向 Chrome / Microsoft Edge；
- 提供账户、权益、设备与会话管理；
- 提供运行日志和用户主动导出的诊断包，便于定位异常。

隐私说明：

GPTLock 不以广告、数据经纪或用户画像为目的收集浏览数据。普通聊天正文不会作为客户端运行日志上传到 GPTLock 服务端。登录账户后，经过敏感字段脱敏的运行日志会上传到 GPTLock 服务端用于故障诊断和可靠性维护；自动验证过程中捕获的固定探针原始响应流保存在本机，并仅在用户主动导出诊断包时离开本地存储。完整数据实践请查看 GPTLock Privacy Policy。

重要说明：

GPTLock 是独立第三方工具，不是 OpenAI 官方产品，也不代表 OpenAI 或获得 OpenAI 背书。实际可用模型、额度、套餐、区域限制及平台行为始终由 ChatGPT / OpenAI 决定；GPTLock 不能创建用户账户本身无权使用的模型或绕过平台限制。

部分核心功能需要用户另外安装 GPTLock Native Core。本地核心由 GPTLock 官网提供，并由用户主动安装和卸载。

## Single purpose / 单一用途

在 ChatGPT 官方网页聊天中保存并应用用户选择的模型与推理偏好，对相关聊天请求执行本地请求锁定，并向用户显示请求/响应证据状态，帮助发现模型偏好未被应用或发生异常切换的情况。

## Reviewer notes 摘要

GPTLock 仅在 `https://chatgpt.com/*` 上执行网页聊天相关的模型偏好锁定与验证。`debugger` 权限用于通过 Chrome DevTools Protocol 观察与该单一用途直接相关的网络请求/响应证据；`nativeMessaging` 用于与用户主动安装的本地 GPTLock Core 通信。扩展不作为通用抓包器使用，不访问任意网站，不出售用户数据，也不使用聊天数据投放广告。
