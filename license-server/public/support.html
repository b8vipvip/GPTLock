公开问题跟踪

GPTWork 官网轻量 Issues 讨论区。公开浏览；登录账户后可提问、提交 Bug/建议并参与用户互助解答。

进入 Issues 讨论区 →
不要公开提交敏感数据。 请勿在 Issues 讨论区粘贴邮箱、密码、Cookie、Authorization、会话 token、支付信息、私人聊天内容或完整诊断包。诊断包只应在你明确知道接收方和用途时主动提供。

提交 Bug 时建议包含

  • GPTWork 扩展版本与 Native Core 版本；
  • Chrome / Edge 版本、Windows / Linux 版本；
  • 问题发生前的最小操作步骤；
  • 插件界面显示的状态与错误代码；
  • 经过人工检查、已移除私人内容后的必要日志片段。

隐私与数据删除

数据处理方式见 Privacy Policy / 隐私政策。删除 GPTWork 账户及关联数据请使用 Data Deletion / 数据删除 中说明的账户中心自助流程。

第三方平台问题

ChatGPT 账户套餐、模型是否开放、额度、区域限制、内容策略和平台服务状态由 OpenAI 管理。GPTWork 无法替用户提升 ChatGPT 套餐、创建额外额度或绕过第三方平台限制。
