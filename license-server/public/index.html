三层结构，
各做各的事。

扩展负责网页侧观察与策略，本地 Core 负责可信执行与审计，服务端负责账户、权益与版本信息。界面尽量简单，但边界保持清楚。

01

正式请求锁定

只针对 ChatGPT 正式 conversation 请求，在发送前检查模型字段；不把 prepare、init 等辅助请求误当成聊天。

02

响应证据确认

把网页真正收到、且能安全解析的模型/推理元数据作为证据。没有证据时保持未确认，而不是制造一个漂亮的绿色勾。

03

本地 Core 与账户

Windows / Linux Native Core、运行日志、自动更新、账户权益与设备管理组成完整工作流。
