支付方式

只有个人微信/支付宝收款码也可以使用：上传二维码后，用户创建订单并扫码付款，后台在“订单”中确认到账后自动开通权益。USDT 可填写欧易生成的 HTTPS 收款链接；也可记录链与地址用于人工核对。
