USDT 套餐价格

为每个会员套餐设置基础 USDT 价格。创建订单时服务端会冻结金额，并可加入不超过 0.000999 USDT 的订单识别尾数，避免多个相同套餐订单同时付款时误匹配。

OKX 自动到账

只使用“读取”权限 API Key。不要授予交易或提币权限。密钥会使用服务端主密钥加密保存，不会返回到浏览器。

尚未读取 OKX 状态

自动流程只在金额、USDT 币种、订单时间窗口以及可用的网络/地址条件匹配，并且 OKX 充值状态达到最终成功时执行。存在多个候选订单时会停止自动开通并要求人工核对。

微信/支付宝静态个人收款码保持“创建订单 → 扫码付款 → 管理员确认实际到账 → 开通会员”，不会因为用户点击“已付款”而自动开通。
