GPTWORK ADMIN · WEBSITE

官网管理

Module CMS + Legal CMS

管理员登录

使用现有 GPTWork 管理员密码。普通官网内容使用结构化字段；法律文档使用受限 Markdown，前台只通过安全 DOM 渲染，不执行管理员输入的 HTML/脚本。

模块化官网

所有前台可见文本字段都带简易样式工具栏，可设置字体、字号、文字颜色、背景色、加粗、斜体和下划线；样式作用于当前字段整段文本。单行输入框的绿色“保存”位于输入框右侧，多行输入框的绿色“保存”位于输入框内部右下角。点击只保存该字段及其样式并立即生效，其它未保存编辑不会一起发布。

预览官网 ↗

全站设置

单行输入框根据内容长度收窄，保存按钮紧邻输入框右侧；SEO 等多行输入框的保存按钮位于输入框内部右下角。

顶部导航

名称、链接和顺序都支持字段级保存；显示开关切换后会自动立即生效。链接仅允许站内路径或 HTTPS。

首页模块

前台文本字段可直接设置字体、字号、颜色、背景色、加粗、斜体和下划线，并使用各字段自己的绿色保存按钮立即发布；模块启停、添加和删除会自动保存。

运营页面

使用教程、版本发布、Issues、支持和账户中心。页面主标题/说明可单字段保存；功能模块标记为“受保护”，只允许启停和安全排序。

法律与合规页面 · Legal CMS

隐私政策、服务条款和数据删除说明的前台可见字段同样带安全文本样式工具栏；保存后直接生成新的法律版本并公开生效。浏览器标题和 SEO 描述保持纯文本。版本历史与安全回滚仍保留。
